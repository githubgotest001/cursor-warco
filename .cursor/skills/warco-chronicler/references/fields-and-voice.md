# 字段规范 与 正史 / 野史文风范例

写档案前读这份。上半是字段的精确规范，下半是语感校准用的真实范例——照着范例的"节奏"写，比记规则更快。

## 一、字段逐条规范

### side
- `main` = 正史（官方档案，脊柱之左）
- `dark` = 野史（民间情报，脊柱之右）
- 只有这两个值，服务端会校验。

### date
- 格式严格 `YYYY-MM-DD`，到日。
- 记**事件发生 / 官宣的那天**，不是写作当天。官宣日以官方口径为准（注意时区：美国时间的官宣，国内看到可能已是次日凌晨——两者都可，同一网站内部保持一致即可）。

### tag（2–4 字中文，给卡片一个"事件性质"标记）
现用词库，可沿用也可按需新拟，但保持这种简短、有性格的风格：

- **正史常用**：起源、首发、融资、并购、里程碑、发布、整合、纪元、惊变
- **野史常用**：冷眼、破防、造词、罢工、事故、羊毛、众怒、谍战、删库、围城、玩梗

### title
- 一句话事件名，约 ≤ 20 字，要有记忆点。
- 好标题给画面 / 反差 / 悬念，不是干巴巴的名词。
  - 平：`Cursor 完成 C 轮融资`
  - 好：`1.0 发布 + C 轮 9 亿美元`
  - 野史更可跳脱：`幽灵客服 Sam 编造政策`、`8 岁小孩姐 45 分钟建站`、`「火箭买编辑器」刷屏`

### summary
- **一段**连续文字，约 60–90 字，时间轴卡片上直接显示。
- 把"发生了什么 + 为什么值得记"浓缩进去，末尾可留一句短钩子。

### detail
- 调阅档案时的详情，**空行分段**，2–4 段。
- 典型三段结构：① 事件经过（含查证到的事实）② 意义 / 背景 / 伏笔 ③ 余味或双线呼应。
- 段内可以有细节和金句，但仍以事实为骨。

### image
- 可空，**默认留空**。图片由用户自行提供（本 skill 不生成、不找图）；如用户给了就填 `/uploads/文件名.png` 或外链 URL。

## 二、正史文风

**特征**：客观克制，先摆事实（时间、主体、数字），再点意义或埋伏笔，末句常有一个不煽情的金句或跨事件呼应。像一位见过大场面、下笔沉稳的财经战地记者。

**范例 1**（tag: 里程碑）
- title：`1.0 发布 + C 轮 9 亿美元`
- summary：6 月 4 日 Cursor 1.0 携 BugBot 发布，次日官宣 C 轮，估值 99 亿；ARR 破 5 亿美元，半数财富 500 强在用。
- detail 首段：`1.0 发布仅一天后，Anysphere 宣布完成 9 亿美元 C 轮，Thrive Capital 领投……官方同时披露：ARR 突破 5 亿美元，超过一半的财富 500 强公司在使用 Cursor，包括 NVIDIA、Uber、Adobe。`
- 末段金句：`彭博称其为「有史以来增长最快的创业公司」。成立三年，站到百亿美元门口。`

**范例 2**（tag: 纪元）
- title：`交割完成，Cursor 并入 SpaceX`
- summary：SEC 文件确认：约 3.89 亿股换股完成，Anysphere 成为 SpaceX 全资子公司。VS Code 分叉，随火箭入列。
- 手感：用可考的硬事实（SEC、股数）立信，末句用"VS Code 分叉随火箭入列"做时间跨度的呼应。

**范例 3**（tag: 起源）
- title：`四个 MIT 同学的赌注`
- summary：Michael Truell 等四人创立 Anysphere，拿到 OpenAI 等首笔种子钱。口号很狂：重新发明编程本身。
- 手感：起源故事也要落到具体的人和钱，末句点出他们的野心，为后续所有事件定调。

## 三、野史文风

**特征**：民间视角，口语、网感、可玩梗，但每条都立在真事上。常带一句"战地记者按"式旁白，把江湖气和记录者的清醒并置。写的是同一段历史的暗面。

**范例 1**（tag: 事故）
- title：`幽灵客服 Sam 编造政策`
- summary：AI 客服凭空编出「单设备登录政策」，Reddit 一夜退订潮。真相：政策不存在，客服是个 bot。CEO 上 HN 鞠躬道歉。
- 手感：真事（Cursor 2025 年 4 月真实事故）+ 反差叙述（"客服是个 bot"），末尾用官方反应收束。

**范例 2**（tag: 羊毛）
- title：`学生认证大翻车`
- summary：薅得太狠，验证紧急收紧：大批非目标区域申请被拒、已领资格被取消，中文圈哀鸿遍野，骂声与晒单齐飞。
- detail 末段可引官方盖棺定论 + 记者按：`一年后官方文档为这场闹剧盖棺定论：「该计划已成为欺诈者的目标。」`
- 手感：民间狂欢 → 官方收紧 → 记者冷眼旁白，三拍。

**范例 3**（tag: 玩梗）
- title：`「火箭买编辑器」刷屏`
- summary：官宣当晚梗图横飞：「Cursor to Mars」「马斯克终于买到了不用自己写代码的方法」。天文学与计算机科学首次合并同类项。
- 手感：纯网感玩梗，但锚定在真实的收购官宣当晚。末句一个俏皮的"合并同类项"收尾。

## 四、双线互文（同一事件的一体两面）

同一天、同一份官方消息，正史记官方视角，野史记民间视角，形成对照。这是本网站的精髓。

**示例：Grok Bot 并入 Cursor（2026-08-26）**
- 正史（tag: 整合）`Grok Bot 并入 Cursor 付费全线`：SpaceX 收编后的首个产品级整合，从顶配下放到 Pro 与全部 Teams，并重置全体周额度。落点在"火箭 × 编辑器 × 大模型首次合流"。
- 野史（tag: 羊毛）`一号多吃 · grok bot 事件`：Pro 及以上含 Grok Bot 独立额度池，社区连夜研究把高级模型消耗指向 bot 额度、"一号多吃、等重置"。落点在民间的白嫖狂欢。
- 正史末段可留钩子：`同一时刻的民间视角，另见野史。`

## 五、查证纪律（再强调）

- 正史每一个精确数字都要有出处；查不到就模糊化（"约""据公开报道"）。
- 越劲爆的消息越要交叉验证，别把假新闻写成正史。
- 野史的核心事件必须真实存在，演绎只作用于语气和细节。
- 你是记者：立场中立，笔下有火，但底线是不造谣。
